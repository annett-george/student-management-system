
# Student Management System

A responsive Student Management System built using
HTML, CSS, and JavaScript.

## Live Demo 
https://annett-george.github.io/student-management-system/

## Features

- Add new students
- View student records
- Search students by roll number
- Edit student information
- Delete students
- Prevent duplicate roll numbers
- Save data using localStorage
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.

## About

This project was built to practice frontend
development, DOM manipulation, JavaScript CRUD
operations, and browser storage.

Note: Student data is stored locally in the
browser and is not shared between users.
